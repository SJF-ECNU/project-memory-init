# 独立桌面工作台首版

## 目标

实现用户确认的 Vue + Electron 独立产品首版：选择项目，左侧选择具体内容分类，中间瀑布流卡片展示文件、概要和更新日期，点击阅读正文。

## 结果

已实现本地项目浏览闭环。读取真实项目 Markdown；分类不是物理搬移，概要为正文摘录。首版只读，不包含编辑、智能整理、语义问答或签名安装包。既有 Obsidian 插件未修改。

## 改动

- [桌面工程](../../../../desktop/package.json)：新增 Vue、Vite、Electron 工程及锁定依赖。
- [文件扫描](../../../../desktop/electron/project-files.cjs)：分类、正文摘录、日期、排除目录、大小提示，保持选择的项目标识以支持刷新。
- [主界面](../../../../desktop/src/App.vue)：项目切换、分类、搜索、排序、卡片、详情与返回位置。
- [主进程](../../../../desktop/electron/main.cjs)：目录选择、项目目录持久化和有限 IPC；隔离渲染层访问。
