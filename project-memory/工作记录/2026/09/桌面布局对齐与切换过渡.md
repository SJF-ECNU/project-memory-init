# 桌面布局对齐与切换过渡

## 目标

修复分类切换时固定标题和搜索等控件上下跳动，以及页面切换生硬。

## 结果

统一浏览标题、说明和工具栏的预留高度和左边界，窗口栏与浏览控件滚动时固定。分类结果淡入淡出，正文和初始化页面使用约 180 ms 淡入淡出与 4 px 位移，控件颜色平滑过渡，尊重系统减少动态效果设置。返回时分别保留浏览与初始化之前的滚动位置；从正文打开初始化后再返回正文，不覆盖正文返回文件列表的位置。当前工作台通过 View → Reload 加载新构建。

- [App.vue](../../../../desktop/src/App.vue)：浏览固定区域、内容与视图 Transition、返回位置。
- [style.css](../../../../desktop/src/style.css)：稳定高度、sticky、短过渡、减少动态效果。
- [浏览测试](../../../../desktop/tests/electron-smoke.mjs)与[初始化测试](../../../../desktop/tests/electron-init-smoke.mjs)：等待过渡结束，位置测量及返回回归。

- 生产构建通过；Node 测试 14/14 通过；两套真实 Electron 界面测试通过。
- 1380 px 窗口：标题区域 y=110，搜索和排序 y=228；800 px 窗口同样位置。最近更新、CLAUDE.md、项目概览、全部内容切换与滚动 400 px 后坐标一致。
- 观察到分类过渡激活，减少动态效果时控件 transitionDuration 为 0s；初始化与正文返回、搜索、刷新、项目切换、窄窗、重启持久化和后台初始化重开/停止回归通过。初始化使用模拟 CLI 进程，不证明真实模型结果。
