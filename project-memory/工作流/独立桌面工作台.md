# 独立桌面工作台

## 目标

脱离 Obsidian，以 Vue + Electron 实现项目选择、具体分类、中央瀑布流卡片和正文阅读。

## 当前状态

浏览闭环和固定区域对齐、切换过渡已完成，已支持基本文件编辑，尚未实现日常智能整理。

## 最新结果

- 应用源码已发布到 origin/project-memory-app，根 README 提供分支克隆与运行入口。

- 更新时间排序提供本地日历分组、组数量和完整年月日；名称排序平铺，最近更新排序控件固定为时间。

- UTF-8 Markdown、纯文本和 dotfile 源码编辑与保存、快捷键、草稿离开提示及外部文件变化拒绝覆盖已验证。

- 独立 desktop 工程，浏览不写文件，路径保留；概要为真实正文摘录，日期为修改时间。
- 分类、搜索、排序、刷新、详情、返回位置及项目持久化已实现。
- 分类切换时标题与搜索排序位置稳定；约 180 ms 过渡，支持减少动态效果，浏览与初始化分别保留返回位置。
- 文件测试、生产构建、Electron 交互测试和 OpenSpec 严格校验通过；具体证据与边界见最新记录。

## 阻塞

无。

## 下一步

通过 project-memory-app 分支运行桌面应用，后续需求继续更新相关 OpenSpec。
