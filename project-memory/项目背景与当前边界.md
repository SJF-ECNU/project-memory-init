# 项目背景与当前边界

本页从当前 checkout 的权威来源提炼接管摘要，不替代源码、OpenSpec、安装说明或实时检查。

## 一句话定位

`project-memory-init` 为多智能体代码仓库提供随 Git 版本化、兼容 Obsidian 的项目记忆和文档关系层；本分支还提供用于只读浏览这些关系的 Memory Constellation Obsidian 插件。

## 产品面与主要子系统

### 独立桌面工作台

- 新增 `desktop/`，使用 Vue + Electron 选择本地项目、按分类浏览卡片并阅读 Markdown、纯文本和 dotfile。文件概要来自正文摘录，日期来自文件修改时间。
- 浏览不写文件，显式编辑保存可写回选中的原文件；用户点击初始化可选择本机 Claude/Codex 执行保留式文档写入。已选目录保存在应用 userData。无日常智能整理、语义问答或签名安装包。当前范围见 [桌面端 README](../desktop/README.md)。

### 项目记忆初始化资产

- 根 Skill、`references/` 和 `assets/` 定义一次性初始化、文档关系层、日常项目记忆 Skill 与智能体入口的保留式生成规则。

### Memory Constellation 插件

- `obsidian-memory-constellation/` 从 Vault 元数据构建稳定二维关系模型，提供范围切换、搜索、缩放、拖拽、单击锁定、双击打开和关联笔记侧栏。

### OpenSpec 变更资料

- `openspec/changes/add-memory-constellation-plugin/` 保存插件范围、非目标、设计、任务和可验收需求；它是行为变更的权威规范入口。

## 核心领域与调用边界

- Vault Markdown、frontmatter 与 Obsidian `resolvedLinks` 是插件读取的关系来源；插件不维护脱离 Git 的全局图谱状态。
- 插件运行在 Obsidian 客户端内，插件没有数据库、后端服务或外部 API；独立桌面端另外提供隔离的本地读取 IPC。
- 插件只能读取和打开笔记；不能写入、移动、重命名或删除 Vault 文件。

## 当前已经具备的关键能力

- README 与 OpenSpec 记录二维语义布局、关系高亮、范围切换、搜索、关联侧栏、动画重播和 Git checkout 后重新建立关系模型的实现范围。
- 当前 `package.json` 提供 `npm test`、`npm run check` 与 `npm run build`；OpenSpec 任务记录插件独立分支发布已完成。
- 本次初始化已建立当前 checkout 的项目记忆、文档关系层、本地日常 Skill 与兼容入口，具体结果见 [[project-memory/工作流/项目记忆初始化]]。

## 明确没有或尚未完整实现

- 不实现 3D、持续力导向漂移、数据库、后端服务或跨 Git checkout 的外部图谱状态。
- 不替换 Obsidian 原生关系图谱，也不修改 Vault 笔记。
- 自动化测试、类型检查和构建不能证明目标 Vault 已安装产物，或所有真实前台交互、动画和视觉效果已验收；OpenSpec 任务表仍列有若干此类待办。
- 仓库未登记生产环境、CI/CD、托管服务或实时在线状态。
