# Project Memory Init 项目记忆

将仓库根目录作为 Obsidian Vault 打开，不要只打开 `project-memory/`。本页是人和智能体共同使用的接管入口；被引用的项目文件仍是权威来源。

## 接管工作

1. 阅读 [[project-memory/项目概览|项目概览]]。
2. 按任务阅读 [[project-memory/项目背景与当前边界|项目背景与当前边界]]、[[project-memory/开发与运维注意事项|开发与运维注意事项]] 或 [[project-memory/环境与部署|环境与部署]]。
3. 选择相关工作流，先读其最近一篇记录；信息不足时再从新到旧追溯，至多读取五篇。
4. 按 [[project-memory/协议|项目记忆协议]] 用当前 Git、代码、配置和 OpenSpec 核对继承状态。
