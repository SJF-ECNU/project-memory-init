# 工作流名称

创建新工作流时，将标题、`workstream`、状态、时间和负责人替换为当前任务的真实值。

## 目标

写入一个有界且可验证的目标。

## 当前状态

写入当前已成立的事实，并链接必要的权威来源。

## 最新结果

写入最近经过验证的结果，不把历史测试或静态文档表述为实时状态。

## 阻塞

- 没有阻塞时写“无”；有阻塞时写明证据、影响和所需输入。

## 下一步

写入下一位参与者可执行的一项明确操作。

## 近期工作记录

- 写入按时间由近到远排列的至多五篇 Obsidian 双链；没有时写“无”。

## 引用

- [[project-memory/协议]]
- 仅链接当前目标仍需要的规范、源码、Issue 或报告。
