# 项目概览

本 checkout 是 `project-memory-init` 的 `project-memory-app` 分支，以 `desktop/` 的 Vue + Electron 项目工作台为产品入口，保留应用初始化所需的根 Skill 与模板。分支从 memory-constellation 的共同历史创建，继承的 Obsidian 插件源码与历史规范不参与桌面应用运行。

## 仓库结构

| 区域 | 职责 | 权威来源 |
| --- | --- | --- |
| 根 `SKILL.md` 与 `references/` | 初始化流程、事实边界和文档关系规则 | [根 Skill](../SKILL.md) |
| `assets/` | 项目记忆、项目文档与智能体入口的可复用模板 | [[docs/索引/初始化资产|初始化资产]] |
| `obsidian-memory-constellation/` | TypeScript/ESBuild Obsidian 插件源码、测试与样式 | [[docs/索引/插件实现|插件实现]] |

| `openspec/` | 应用及继承插件的提案、设计、任务和需求 | [[docs/索引/变更规范|变更规范]] |

## 当前架构锚点

- `desktop/` 新增独立 Vue + Electron 应用，分类与卡片阅读直接扫描本地 Markdown、纯文本和 dotfile，详见 [桌面端 README](../desktop/README.md) 与 [设计](../openspec/changes/add-project-desktop/design.md)。浏览不写文件，支持已有文本文件编辑保存和用户发起本机 Claude/Codex 初始化；尚无日常智能整理或安装包。

- 插件从当前 Obsidian Vault 的 Markdown、frontmatter 与 `resolvedLinks` 建立图模型；它不创建数据库，也不移动、重命名、删除或写入 Vault 笔记。
- 插件工程的构建、类型检查和测试入口在 `obsidian-memory-constellation/package.json`；安装产物是构建生成的 `main.js` 加 `manifest.json` 与 `styles.css`，构建产物不提交到本仓库。
- 当前 Git、分支、版本、目标 Vault 安装状态和前台视觉验收属于动态事实，必须在任务开始时重新检查。
