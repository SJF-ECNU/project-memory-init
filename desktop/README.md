# 项目工作台 · 桌面端

独立于 Obsidian 的 Vue + Electron 本地应用。左侧选择项目和内容分类，中央以瀑布流展示真实 Markdown 和文本文件；卡片显示标题、原始相对路径和正文摘录，卡片下显示文件更新日期。点击阅读正文，返回保留浏览位置。

## 运行

需要 Node.js 22.12 或更新版本。

```bash
cd desktop
npm ci
npm run build
npm start
```

首次启动点击“选择项目目录”。项目目录列表存储在 Electron userData，不导入或移动项目文件。普通浏览不写文件；编辑保存写回选中的原文件，初始化由所选 Agent 写入项目文档。开发使用 `npm run dev`。也可以通过 `npm start -- --project=/absolute/project/path` 打开指定项目。

如 Electron 二进制下载失败，先确认当前网络能访问 GitHub Releases，然后执行 `npx install-electron --no`。代理只在当前安装命令中配置，不修改应用网络或系统设置。

## 一键项目初始化

1. 选择或添加本地项目目录，点击右上角“一键初始化”。
2. 在中央面板选择已安装的 Claude Code 或 Codex；显示版本仅证明 CLI 可启动，不代表已经登录。
3. Codex 可在面板选择本机 CLI 目录里的模型，默认展示第一个候选，也可选择沿用 CLI 默认模型。点击“开始初始化”，使用已有登录执行保留式初始化；显式模型只影响本次运行，不改全局设置。
4. 面板展示输出与结果，结束后自动刷新文件分类和卡片。点击返回文件浏览、左侧分类、切换项目或在面板内按 Esc 都可离开初始化；执行中的任务继续在后台运行，再打开入口可查看原项目任务。

初始化复用仓库 `SKILL.md`、`references/` 和 `assets/`，构建时复制到 `dist/initializer/`，无需用户额外安装初始化 Skill。开发模式直接读取仓库资产。范围是项目记忆、文档索引、项目本地日常 Skill 和智能体入口，已有文件保留式补齐；不授权改应用代码、提交、发布或生产配置。

仅支持 Claude 和 Codex CLI，不自动安装工具、不管理凭据。未检测到时先在本机安装，再点击“重新检测”。若未登录或权限不足，先在终端用 `claude` 或 `codex login` 完成配置，再重试；Claude 模型沿用本机设置；Codex 支持本次选择。候选目录不保证账号一定有访问权限，服务返回错误仍会展示。CLI 可能按已有订阅或供应商配置消耗额度。

Claude 使用文档读写许可和受限调查命令，本次调用不自动加载 MCP，CodeGraph 通过 CLI 调查，Codex 使用 workspace-write 并仅显式允许当前项目的 `.agents/` 子目录写入；不使用全权限绕过选项。项目自身的规则、权限或沙箱可能阻止某些写入，面板会保留失败信息。若辅助操作被拒绝但 Agent 已通过其他工具完成，核心入口完整时会显示完成并保留权限警告；必要文件缺失或最终错误仍视为失败。Claude 的 API 重试会显示 HTTP 状态，不再只显示启动成功。停止会终止子进程，不撤销已经写入的文件。

一次只执行一个初始化。输出只驻留本次主进程会话，不把完整 Agent 输出保存到项目记忆。完成后检查必要入口文件是否存在，不把文件存在检查等同于内容质量验收；仍应阅读生成内容。

## 浏览功能范围

- 已选项目切换、全部内容、最近更新，以及按文件名和路径识别的非空分类。
- 浏览标题、说明与搜索工具栏使用稳定高度，滚动时固定；分类、正文与初始化页面使用约 180 ms 过渡，尊重系统减少动态效果设置。
- 最近更新按今天、昨天、近 7 天及更早年月分组，显示数量与完整更新日期；名称排序不分组。
- 标题、路径、正文搜索；名称和更新时间排序；显式刷新读取当前项目文件。
- 同名文件用相对路径区分；概要为正文摘录，不是模型生成或人工确认的摘要。
- Markdown 安全阅读；双链显示可读名称，当前正文链接不跳转，图片与远程媒体不加载。
- 支持已有 UTF-8 `.md`、`.txt` 和文本 dotfile（例如 `.gitignore`、`.env`、`.npmrc`）编辑；初始化入口允许所选 Agent 在项目内生成/补齐文档。尚无日常自动整理、语义问答、收藏或有效性状态判定。
- 支持隐藏目录中的上述文件；跳过 `.git`、`.obsidian`、`.codegraph`、符号链接和依赖/构建目录；二进制或非 UTF-8 文件不可编辑；超过 2 MB 或无法读取的文件显示跳过提示。
- 当前是源码运行版，尚未制作签名安装包。

## 文件编辑

打开卡片后点击“编辑文件”，在源码编辑框中修改，点击“保存”或按 ⌘/Ctrl+S 写回。Markdown 保存后恢复正文预览，文本和 dotfile 按原文显示，不解析 HTML。卡片标题、概要和修改日期随保存更新。

取消编辑、切换分类/项目、进入初始化或关闭窗口时，有未保存内容会提示继续编辑或放弃。外部程序已经修改文件时保存会拒绝覆盖并保留草稿；可先复制草稿，再返回并刷新查看最新内容。保存使用同目录临时文件替换并保留权限；不保证与其他程序同时写入时的跨进程事务。当前不包含新建、重命名、删除或富文本编辑。

## 验证

```bash
npm test
npm run build
npm run test:ui
```

UI 测试启动真实 Electron，用当前仓库验证浏览，验证 Markdown/文本/dotfile 保存、草稿保护和外部冲突，并用临时模拟 CLI 进程验证初始化选择、输出、结果刷新、失败与停止；模拟 CLI 不证明真实模型初始化质量。截图保存在被 Git 忽略的 `test-results/`。

显式运行真实 CLI 验证（使用已有账号额度，仅写入临时示例项目）：`node tests/real-init-smoke.mjs claude` 或 `node tests/real-init-smoke.mjs codex gpt-5.6-luna`（最后一项是本次模型，可省略沿用 CLI 默认）。报告保留在 `test-results/`。

### 本机转发服务排查

若 Claude 反复重试或返回 502，先检查 CC Switch 的请求状态和供应商出站连接。CLI 进程的代理环境不会替另一个已运行的 CC Switch 设置出站代理。应在 CC Switch「设置 → 路由 → 全局出站代理」配置实际可用的本地代理并测试；具体地址取决于本机环境，不由工作台硬编码。该设置影响 CC Switch 的出站请求，不修改系统代理。
