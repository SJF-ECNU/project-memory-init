# 本机 Agent 初始化设计

## Context
当前应用支持只读 Markdown 浏览。没有 CodeGraph 索引，调查限定于 desktop 主进程、preload 和 Vue 界面。初始化复用根 SKILL.md、references 与 assets，不另写一套初始化规则。

## Decisions
- 用户在当前项目打开“一键初始化”面板，选择 Claude 或 Codex，点击“开始初始化”即授权该项目的保留式文档写入。显示项目路径、生成范围和 CLI 使用本机登录设置的说明。
- 检测 PATH 与常见用户安装目录，只运行候选 executable 的 --version，未检测到则禁用选项并提供安装/登录指引。检测不等于登录验证。
- 构建后复制根初始化 Skill 及其规范/模板到 dist/initializer，开发模式读取仓库源资产。提示词以带文件名的正文打包，通过 stdin 发送，不授予应用资源目录额外写入权限。
- Claude 使用 print、stream-json、verbose，acceptEdits 以及文档读写工具和受限的只读调查命令；本次调用使用空的 strict MCP 配置，避免无关用户 MCP 连接阻塞初始化，CodeGraph 沿用 CLI；Codex 使用 exec、json、workspace-write 和非交互审批策略。保留用户登录，Claude 沿用默认模型，Codex 可显式选择本次模型，不使用绕过所有权限/沙箱的选项。真实验证发现 Codex 默认保护 .agents：主进程只创建当前项目的 .agents 目录，并通过 --add-dir 显式授权这个子目录；若它指向项目外部则拒绝执行。
- 仅允许已选项目与固定 agent ID，不允许渲染层传入命令、参数或任意可执行路径。spawn 使用参数数组且不开 shell，cwd 为项目根。
- 同一应用一次只运行一个初始化，避免并发修改；执行期间可浏览其他分类或项目，再次打开面板恢复执行状态。状态只驻留主进程，不持久化完整 Agent 日志。
- 解析 JSONL，展示文本消息、工具动作名称与错误；不回显提示词、凭据或原始工具输出。日志有长度上限。退出错误、Claude is_error、Codex turn.failed 与缺失入口都不标为成功；permission_denials 保留警告，若最终正常完成且核心产物完整则报告入口已生成并提示核对内容。
- 成功/失败/取消后刷新对应项目；停止终止子进程组，退出应用终止活动进程。停止不回滚 Agent 已经写入的文件，界面明确提示。
- 结束后检查主要记忆文件、协议、模板、工作流、本地 Skill 和 Agent 入口；文档索引和实际内容质量仍由 Skill 的验收与用户阅读确认，不将存在检查冒充语义质量证明。

## Verification
临时可执行 CLI 测试真实 spawn、stdin、cwd、流事件、失败、取消、重复启动和写入产物；Electron 使用临时 PATH 中的 CLI 运行完整 UI，验证检测、选择、进度、刷新与错误。另用本机两个真实 CLI 在隔离临时项目做有界运行，区分模拟测试与真实模型结果。

## CLI 兼容与服务诊断修复
实测确认 Codex 0.148.0 的本地目录不包含配置中的 gpt-6.1-sol，已有支持模型可完成初始化。界面从 `codex debug models --bundled` 获取显示模型并提供本次选择，保留沿用默认项；不改全局配置或静默换模型。模型作为参数数组单项传递，限制为模型标识，不接受额外命令。
Claude 的本机 CC Switch 转发请求返回 502，上游 DNS/连接失败，不是项目生成代码阻塞。继续沿用用户指定的 CC Switch；展示 system/api_retry 的状态和安全错误摘要。网络修复发生在本机 CC Switch 的出站设置，不把固定本机代理写入产品。
验证目标：模拟测试证明模型参数、非法输入拒绝和重试提示；真实两个 CLI 在临时示例项目生成完整入口并保留原文；外部网络修复单独记录配置变化和实测证据。

退出初始化视图：分类选择和用户切换项目会关闭面板，Esc 或返回按钮也可关闭；不调用停止任务。后台完成触发的同项目刷新保留当前视图。
