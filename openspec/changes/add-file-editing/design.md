# 设计

没有 CodeGraph 索引，调查现有扫描、IPC、Vue 阅读与交互测试。扩展扫描到 .txt，纯文本按原文阅读，不解析 Markdown。编辑使用 textarea，独立草稿，保存成功更新卡片和正文。保存 IPC 仅允许已选择项目内现有、非内部/依赖路径的常规 .md/.txt 和文本 dotfile 文件，拒绝符号链接、二进制和非 UTF-8 数据，限制 2 MB。以读取时原文比较磁盘原文，外部变更时拒绝覆盖；不引入哈希或版本机制。主进程读取原文，写入同目录临时文件、保留权限，再次比较原文后 rename 替换，失败清理临时文件；避免直接截断原文件，普通测试验证路径边界与冲突。外部程序同时写入仍需使用者协调，不宣称跨进程事务。离开编辑内容、切换项目与关闭窗口提示未保存修改；保存失败保留草稿。
