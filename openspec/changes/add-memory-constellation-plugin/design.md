# 设计

## 分支分工

`main` 继续发布轻量的 Project Memory Skill、跨 Agent 同步规范和初始化模板，不纳入插件源码、依赖或插件 OpenSpec。`memory-constellation` 从共同的 Git 历史分出，保留现有插件子目录和测试结构，使用独立的分支首页与源码安装说明。核心 Skill 的说明以 `main` 为准；插件更新不整体合并回 `main`。本次仅发布仓库分支，不创建 GitHub Release 或声称已经上架 Obsidian 社区商店，也不修改现有 Vault 安装。

## 视觉方向

界面采用中性近黑背景与低饱和节点配色。暖银香槟色只用于首页类核心，灰紫用于稳定记忆，雾蓝用于工作流，低亮度蓝灰用于记录与普通文档，Agent 入口为银灰。色彩集中在节点及悬停关系端点，控件和正文仍保持黑白灰；配合尺寸和标签保留语义层级，避免纯灰度导致分类不可分辨。

主要节点具有透色内层、渐变薄边与两段细反光，连线能够透过玻璃内层。小记录与普通文档保持较实的颜色和细轮廓，不使用空心玻璃或额外高光堆叠，以保证缩小后仍然可见。局部高亮通过节点、线条和文字的连续透明度过渡建立层次；首次入场渐进显现，镜头定位平滑过渡。节点位置保持稳定，不添加 3D、星点纹理或持续自转。

浮动搜索、导航与悬停提示采用圆润的玻璃胶囊：半透明底层、背景模糊、断续边缘反光与指针跟随高光，按钮按下轻微形变并回弹。背景模糊仅用于操作层，不模糊图谱内容。效果参考 Apple Liquid Glass，但使用 CSS 和 Canvas 实现，并非系统原生材质，也不模拟真实光学折射。减少动态效果时禁用跟随高光和形变；减少透明度或不支持背景滤镜时，控件使用不透明灰色底层。

搜索输入在悬停、聚焦与按下时显式保持透明，避免 Obsidian 的宿主输入样式覆盖。键盘焦点由整个搜索控件胶囊的细轮廓提示，不在胶囊内部增加矩形背景。

工具栏采用三栏布局：搜索区可缩小，范围开关固定为 104px，标签模式固定为 54px。胶囊宽度仅响应窗口尺寸，不响应“记忆 / 记忆 + 文档”或“简洁 / 全景”的文字变化，切换时搜索图标、分隔线和外轮廓保持原位。

中性幕布柔光位于 Canvas 下方、浮动控件后方，整张视图统一跟踪指针。光纹尺寸为 160px，使用单一高斯衰减与逐像素随机透明度舍入，减轻 8 位暗部渐变的同心色带。纹理每次打开视图只生成一次，不随动画改变噪点。独立按需动画以 45ms 时间常数追随指针，移动时沿运动方向轻微拉伸（上限 22%），停下后恢复圆形并停止调度，不请求图谱渲染帧。

进入搜索胶囊时柔光不断开，胶囊背景模糊从 12px 平滑加强至 26px；仅背景被模糊，文字和节点保持清晰。进入视图时柔光直接定位到当前位置，离开视图、取消指针或窗口失焦时淡出并取消待执行的动画，卸载视图时一并清理。触屏与减少动态效果时禁用跟随柔光。

界面最重要的记忆点是：用户打开后第一眼能看见项目的「当前主脉络」，而不是所有节点同时争抢注意力。

## 关系模型

`graph-model.ts` 接收与 Obsidian API 无关的笔记摘要和已解析链接，负责：

- 根据路径与 frontmatter 分类节点；
- 排除模板、嵌套旧副本与 `docs/superpowers/`；
- 折叠重复连线；
- 为时间戳工作记录生成短标题；
- 生成确定性语义布局和节点优先级。

关系数据每次从当前 Vault 重建，因此 Git checkout 切换后只需刷新 Obsidian 元数据，不存在另一份持久图数据。

## 布局与降噪

- `project-memory/首页.md` 固定为中心锚点。
- 稳定记忆与 Agent 入口位于内轨道。
- 工作流位于中轨道，相关工作记录就近分布在外轨道。
- 文档模式下，`docs/首页.md` 作为次级锚点，分类索引和文档围绕它分布。
- 默认所有节点以正常亮度显示，不自动高亮首页；未选中时悬停强调该节点及其直接邻居，移开恢复全图。明确单击选中后保持其关系高亮，直到取消或选中其他节点。
- 标签按节点优先级、缩放级别和聚焦状态渐进显示，避免默认显示全部长文件名。

## 交互与性能

搜索复用当前图模型，不额外扫描正文或维护索引。标题、原始文件名和路径统一归一化后，多个空格分隔关键词取交集；按精确标题、前缀、标题子串与路径命中的顺序排序。同名结果各自保留类型和完整路径。列表使用独立定位浮层，不挤占胶囊栏位；列表高度受当前画布约束，长结果内部滚动。键盘通过 combobox/listbox 的活动选项选择，中文输入法确认不触发跳转；定位后将焦点交给画布，按 Enter 即可打开选中的笔记。范围切换与元数据刷新时重新检索，保持 Git 跟随性。

节点命中使用视口坐标与半径计算，不需要 DOM 节点树。选中状态优先于临时悬停；未选中时，移到空白处、离开画布或取消拖拽后恢复全图。单击在选中和取消之间切换，搜索定位同样选中；空白处、Escape、适应全图与重播清除锁定。双击通过 Obsidian Workspace API 打开原笔记，第二次 click 不重复切换，拖拽后的 click 被忽略。Vault 变化和 metadata `resolved` 事件使用短防抖重建，保留仍有效的选中项并刷新关联列表，清理已删除或移出范围的选中项。

选中后展开非模态玻璃侧栏，直接从当前图模型的一跳邻接关系生成完整、去重的关联笔记列表，不伪造父子或入链/出链方向。标题与路径不截断，可在列表内筛选；条目单击定位并选中，独立 ↗ 按钮打开文件。侧栏首次放在点击节点的另一半画布，宽度不超过半幅，采用覆盖层不挤动 Canvas 或相机，避免破坏双击目标；连续选择时保持侧栏方位，关闭后不再接收焦点或指针事件。搜索浮层位于侧栏之上，窄窗列表与卡片可滚动。

节点与关系线保留各自的过渡进度，快速切换目标时从当前画面继续动画。未选中时鼠标离开后全部节点渐回正常亮度；静止且过渡结束时停止绘制。系统开启减少动态效果时立即显示最终状态。标签尝试多个方向避让，优先保证当前节点与直接邻居可读。

范围切换使用独立的短暂显示帧，真实图模型立即反映当前范围，离场节点仅参与绘制，不能被搜索或点击。入场顺序沿首页的实际链接广度展开，断开的分组仍会出现；层级延迟上限 390ms，节点舒展 450ms，整体生长最长约 840ms，而非按节点总数依次等待。节点从关联父节点方向短距就位、轻微放大，曲线按二次 Bézier 子段逐渐延伸，标签在节点显现后再出现。已存在节点保留当前坐标、透明度与材质比例，离场节点 280ms 淡出。快速反向切换采样当下显示帧，不回到旧起点。一次时间轴由既有按需 RAF 驱动，结束即释放临时显示数据。

重播按钮位于右下角导航，使用独立的回转箭头，不改变搜索胶囊。它适应当前范围、清除临时焦点、从空白开始重播；根据当前图谱的实际时间轴统一缩放到 10 秒，节点、关系线及依赖节点显现的标签保持原有节奏比例。范围切换和初次入场仍使用短过渡。重复点击替换当前动画，不累积动画队列。开启减少动态效果时不播放生长，仍适应全图。

首页、稳定记忆、工作流和文档分类的名称属于必要信息。这些标签不受普通标签数量上限约束，小节点不阻挡它们的文字；四个贴近位置不足时，尝试外移位置与细引导线，保证大节点不会在密集文档中丢失名称。

## 风险与边界

- 大型 Vault 的文档全景可能产生较多节点；通过默认只读 Project Memory、渐进标签和静态布局降低开销。
- 不使用 Obsidian 未公开 API，不依赖原生图谱的 DOM 或内部渲染器。
- 没有数据库、并发写入、迁移或外部服务风险。
