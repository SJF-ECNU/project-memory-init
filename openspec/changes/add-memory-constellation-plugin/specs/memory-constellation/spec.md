## ADDED Requirements

### Requirement: 插件以稳定的 2D 层级展示项目记忆

插件 SHALL 将当前 Vault 的 Project Memory 双链渲染为二维语义布局，并保持节点位置稳定。

#### Scenario: 用户首次打开记忆星图

- **WHEN** Vault 中存在 `project-memory/首页.md` 以及相关工作流和工作记录
- **THEN** 首页显示为中心锚点，稳定记忆、工作流和工作记录按语义层级分布
- **AND THEN** 节点不使用持续力导向漂移或 3D 镜头运动

### Requirement: 默认画面优先主脉络可读性

插件 SHALL 默认以正常亮度展示所有节点，并渐进显示标签。

#### Scenario: 图中包含大量时间戳工作记录

- **WHEN** 用户没有选中或悬停任何节点
- **THEN** 所有节点恢复正常亮度，不自动锁定首页
- **AND THEN** 长时间戳文件名不会同时占据主画面

#### Scenario: 文档分类周围有密集的小节点

- **WHEN** 可见区域中的首页、记忆、工作流或文档分类标签与附近节点冲突
- **THEN** 这些重要节点优先保留名称，尝试外移标签并通过细引导线连接
- **AND THEN** 小节点标签先退让，重要节点不会仅因四个候选位置被占据而丢失名称

### Requirement: 用户可以渐进探索关系

插件 SHALL 支持节点聚焦、范围切换、搜索、平移、缩放和打开源笔记。

#### Scenario: 用户悬停一个节点

- **WHEN** 没有选中节点，鼠标进入任意节点的命中区域
- **THEN** 无需点击即可突出该节点、直接相连的节点、关系线和标签
- **AND THEN** 鼠标移到空白处或离开画布后，全部节点恢复正常亮度，局部关系高亮消失

#### Scenario: 用户查看一个工作流

- **WHEN** 用户单击工作流节点
- **THEN** 锁定该笔记及直接关系，鼠标移开或经过其他节点时保持已选关系集合；再次单击同一节点取消锁定
- **AND THEN** 用户双击时通过 Obsidian Workspace 打开对应笔记

#### Scenario: 用户阅读密集节点的直接关联

- **WHEN** 用户选中节点
- **THEN** 在不挤动画布、不覆盖首次点击位置的侧栏中展示完整直接关联列表，包括标题、类型、路径及筛选
- **AND THEN** 单击条目定位并选中关联笔记，独立打开按钮直接打开文件；侧栏不会因鼠标悬停其他节点而改变内容

#### Scenario: 用户取消锁定或节点被移除

- **WHEN** 用户点击空白处、按 Escape、关闭侧栏，或选中节点已不在当前范围或 Vault 中
- **THEN** 清除锁定、收起侧栏，未悬停时恢复全图；拖拽不改变选中项，有效选中项在数据刷新后保留

### Requirement: 视觉语言保持克制并融入 Obsidian

插件 SHALL 使用中性黑灰背景与控件，以低饱和香槟、灰紫、雾蓝和蓝灰节点配合尺寸区分语义层级，不使用高饱和红绿对比、3D、星空纹理或持续呼吸动画。

#### Scenario: 用户阅读不同层级的节点

- **WHEN** 用户在正常亮度下查看首页、稳定记忆、工作流与工作记录
- **THEN** 不同类别具有可区分的色调，主要节点显示透色玻璃内层与边缘反射
- **AND THEN** 小记录和普通文档保持较实的颜色，不因玻璃透明度而退化为难以辨识的空心圈

#### Scenario: 用户操作浮动控件

- **WHEN** 用户在搜索或导航玻璃胶囊上移动指针、按下按钮并移开
- **THEN** 玻璃高光跟随指针，按钮轻微形变后回弹，移开时高光复位
- **AND THEN** 图谱的悬停焦点不受控件高光影响，减少动态效果时玻璃反光保持静止且无按压形变

#### Scenario: 用户悬停或聚焦搜索输入

- **WHEN** Obsidian 为输入框应用默认悬停或焦点样式
- **THEN** 插件搜索输入仍然透明，不出现矩形灰色底块
- **AND THEN** 键盘焦点通过控件胶囊轮廓明确呈现

#### Scenario: 用户切换范围或标签密度

- **WHEN** 用户切换“记忆 / 记忆 + 文档”或“简洁 / 全景”
- **THEN** 搜索胶囊的外轮廓、搜索图标和分隔线位置不因按钮文字长度而改变
- **AND THEN** 窗口变窄时只压缩搜索输入区，两个开关保留稳定的栏位

#### Scenario: 图谱处于静止状态

- **WHEN** 用户没有悬停或拖动画布
- **THEN** 背景关系保持低对比度，主要节点与必要标签形成清晰层级
- **AND THEN** 界面不显示与关系阅读无关的装饰卡片或图例

#### Scenario: 鼠标从幕布移入搜索胶囊

- **WHEN** 用户在图谱内移动鼠标并进入浮动搜索控件
- **THEN** 同一层中性柔光跟随指针并继续位于玻璃后方，玻璃背景模糊平滑增强
- **AND THEN** 输入文字不被模糊，图谱节点聚焦规则不变，柔光移动不请求图谱渲染帧

#### Scenario: 鼠标移动并停止

- **WHEN** 用户移动鼠标后停止
- **THEN** 160px 范围内的柔光缓动追随，轻微拉伸后恢复圆形，过渡结束即停止动画帧
- **AND THEN** 使用单次生成的抖色高斯纹理减轻渐变色带，不叠加同心光圈或持续闪动噪点

#### Scenario: 用户离开幕布或不适合使用跟随光效

- **WHEN** 指针离开视图、取消交互、窗口失焦，或用户使用触屏与减少动态效果
- **THEN** 跟随柔光淡出或禁用，不在幕布边缘留下固定亮斑

#### Scenario: 悬停动画已结束

- **WHEN** 用户停止交互且相机与透明度均达到目标状态
- **THEN** 视图停止请求新的渲染帧，下一次交互或数据变化时恢复绘制
- **AND THEN** 系统开启减少动态效果时直接绘制最终状态

### Requirement: 关系生长与范围切换连续

插件 SHALL 在初次入场和范围切换时使用约一秒内的节点舒展、关系曲线延伸及延后标签，展示当前范围的关系层级；用户主动重播 SHALL 使用 10 秒时间轴。播放时长不得按笔记数量线性增加。

#### Scenario: 切换范围并快速反向切换

- **WHEN** 用户切换“记忆 / 记忆 + 文档”，或在动画结束前反向切换
- **THEN** 已有节点从当前画面连续衔接、相机平滑调整，新节点沿关系分批出现，移除节点短暂淡出
- **AND THEN** 离场节点只用于绘制，不再出现在搜索及命中检测里；动画结束后不保留旧节点或关系

#### Scenario: 重播当前图谱

- **WHEN** 用户点击右下角“重播生长动画”
- **THEN** 在当前范围用 10 秒从空白重新展开所有节点，包含无连接节点，不修改笔记或搜索栏尺寸；仅重播放慢，范围切换保持短过渡
- **AND THEN** 重复点击替换当前动画，不排队；空图不持续绘制，减少动态效果时直接显示最终图谱

### Requirement: 搜索结果可辨认与可操作

插件 SHALL 在当前图谱范围内按显示标题、原始文件名及路径进行即时搜索，支持空格分隔的多个关键词及英文大小写、全半角归一化；不读取笔记正文。精确标题匹配 SHALL 优先于前缀、子串及路径匹配。

#### Scenario: 用户输入查询

- **WHEN** 用户输入或修改搜索词
- **THEN** 展示匹配列表、笔记类型及完整路径，标明当前范围与数量；没有匹配时提供换词或扩大范围的提示
- **AND THEN** 下拉浮层不占据工具栏布局空间，也不自动移动或高亮图谱

#### Scenario: 用户选择搜索结果

- **WHEN** 用户用方向键选择结果并按 Enter，或单击结果
- **THEN** 图谱定位并选中对应节点，锁定其直接关系并显示关联侧栏
- **AND THEN** ⌘/Ctrl+Enter 或修饰键单击在新标签打开笔记，Escape 收起列表而不清空查询；中文输入法确认不触发跳转

#### Scenario: 查询期间范围或文件变化

- **WHEN** 图谱范围切换或 Vault 完成重建
- **THEN** 已展开的搜索结果使用新图谱重新检索，不允许跳转到已移除的结果

### Requirement: 可视化始终反映当前 Vault

插件 SHALL 从当前 Vault 文件和已解析链接构建视图，不保存脱离 Git 的笔记关系副本。

#### Scenario: Git checkout 改变了项目记忆

- **WHEN** Obsidian 完成当前 checkout 的 Vault 元数据刷新
- **THEN** 星图从当前文件与 `resolvedLinks` 重建
- **AND THEN** 不继续显示上一 checkout 独有的节点或关系

### Requirement: 插件不修改项目笔记

插件 SHALL 把 Vault 内容视为只读数据源。

#### Scenario: 用户浏览或刷新星图

- **WHEN** 插件构建模型、搜索、聚焦节点或打开源笔记
- **THEN** 插件不创建、修改、重命名或删除任何 Vault 文件
