# 设计

## Context
当前仓库只有独立 Obsidian 插件；没有 CodeGraph 索引。新应用独立放在 desktop，不迁移或修改现有插件。保留项目文件作为事实来源。

## Decisions
- Vue 负责展示，Electron 主进程负责目录选择和 Markdown 扫描；隔离渲染进程，通过有限 preload API 读取项目。
- 项目列表保存在应用 userData，仅保存用户选过的目录。禁止渲染进程指定任意读取路径；扫描跳过符号链接、隐藏目录、依赖和构建目录。
- 分类按文件名和相对路径确定，规则集中管理；CLAUDE/AGENTS/GEMINI 单独分类，日志、设计、任务、决策、环境等按目录语义归类，剩余进入其他文档。空分类隐藏。
- 标题读取首个一级标题，否则使用文件名；摘要去除 frontmatter、代码块和 Markdown 标记，截取真实正文。日期来自文件修改时间，不宣称内容有效性。
- 浅暖灰背景、冷蓝选中态、克制边框；分类侧栏与中央 CSS columns 瀑布流分工。卡片高度有限，日期位于卡片外。
- 正文用 Markdown 渲染并消毒，远程资源不加载，禁止导航与弹窗。详情返回恢复分类、搜索和滚动位置。
- 显式刷新重新扫描当前 checkout 文件。首版不提供写入或模型能力。

## Verification
使用临时真实文件测试分类、摘要、扫描排除、项目隔离与刷新；构建后用 Electron 实际加载仓库，验证项目切换、搜索、卡片打开与返回，以及窄窗布局。检查渲染控制台错误。

## 对齐与切换动效
保持现有浅色视觉体系。浏览页标题和说明使用固定行高与预留高度，工具栏与标题共享左边界；窗口栏与浏览工具区在滚动中保持稳定。进入初始化时回到页首，返回时恢复先前浏览位置。
分类只切换文件内容，以约 180 ms 淡入淡出；初始化、正文与浏览视图以淡入淡出和极小位移过渡，布局高度不做动画。选项和控件使用一致的颜色/边框过渡。减少动态效果偏好关闭这些动画。
验收：宽/窄窗口逐类切换测量标题、搜索和排序位置，检查过渡确实存在、减弱动态效果关闭、详情返回位置和初始化退出不回归。

## 时间层次

更新时间排序按本地日历日分今天、昨天、近 7 天，更早按年月分组，分组显示数量，省略空组；每张卡片显示完整年月日时分。未来时间单独标识，不冒充今天。名称排序不分组；最近更新始终按更新时间，排序控件不可切到名称造成误解。保留现有瀑布流与稳定浏览区域。

## 应用分支发布

桌面应用通过 project-memory-app 独立源码分支发布，README 指向 desktop 的安装、运行和验证命令。保留共享初始化资产与继承历史；旧插件源码不参与桌面运行。提交源码、锁文件、规范、文档和接管记录，排除 node_modules、dist、test-results、生成 main.js。源码发布不等同于签名安装包。
