# 〔项目名称〕项目记忆

将仓库根目录作为 Obsidian Vault 打开，不要只打开 `project-memory/` 子目录。本页是人和智能体共同使用的稳定入口；被引用的项目文件仍是权威来源。

## 接管工作

1. 阅读 [[project-memory/项目概览|项目概览]]。
2. 按任务读取 [[project-memory/项目背景与当前边界|项目背景与当前边界]]、[[project-memory/开发与运维注意事项|开发与运维注意事项]] 或 [[project-memory/环境与部署|环境与部署]]。
3. 选择下方相关工作流，默认读取其链接的最近一篇工作记录。
4. 如果最近记录不足以解释当前状态、决策、阻塞或依赖，按时间由近到远继续查阅相关历史和引用来源，信息足够后停止。
5. 按 [[project-memory/协议|项目记忆协议]] 核对 Git、当前代码/配置和变更规范后再继续。
