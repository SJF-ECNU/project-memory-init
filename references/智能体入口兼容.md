# 智能体入口兼容

项目记忆只维护一套内容分流规则。根 `AGENTS.md` 是规范源；其他厂商文件只负责让对应客户端进入同一套规则，不复制项目背景、进展或部署内容。

## 官方入口

| 智能体或客户端 | 项目级入口 | 初始化策略 |
| --- | --- | --- |
| OpenAI Codex | `AGENTS.md` | 注入统一 Project Memory 与信息分流片段。 |
| Claude Code | `CLAUDE.md` 或 `.claude/CLAUDE.md` | 根 `CLAUDE.md` 使用 `@AGENTS.md` 导入规范源；保留已有 Claude 专属规则。 |
| Gemini CLI | `GEMINI.md` | 使用 `@./AGENTS.md` 导入规范源；保留已有 Gemini 专属规则。 |
| GitHub Copilot | `.github/copilot-instructions.md` | 写入指向 `AGENTS.md`、项目记忆首页和协议的短入口。 |
| Cursor | `AGENTS.md`；复杂作用域可用 `.cursor/rules/*.mdc` | 直接复用根 `AGENTS.md`，不额外创建 Cursor 规则。 |
| Windsurf | `AGENTS.md`；复杂作用域可用 `.windsurf/rules/*.md` | 直接复用根 `AGENTS.md`，不额外创建 Windsurf 规则。 |
| Cline | `AGENTS.md`；原生规则目录为 `.clinerules/` | 直接复用根 `AGENTS.md`，不额外创建 Cline 规则。 |
| Devin | `AGENTS.md` | 直接复用根 `AGENTS.md`。 |
| JetBrains Junie | 根 `AGENTS.md` 或 `.junie/AGENTS.md` | 默认复用根 `AGENTS.md`，不创建第二份完整规则。 |
| Continue CLI | `AGENTS.md` | 直接复用根 `AGENTS.md`；Continue IDE 已使用 `.continue/rules/` 时，可按需增加短入口。 |
| Aider | 用户指定的只读约定文件，常见为 `CONVENTIONS.md` | 不默认创建；使用者明确要求时才生成短入口并通过 Aider 配置或 `--read` 加载。 |

## 初始化写入规则

1. 始终保留并复用根 `AGENTS.md`。文件存在时直接在原文件中补齐，不能新建替代文件、改名或整体重写；只有根 `AGENTS.md` 不存在时，才使用 `assets/智能体入口/AGENTS项目记忆片段.md` 创建最小文件。
2. 已有 `Project Memory` 或 `Information Placement` 章节时在原位置合并缺失规则；没有时，把模板片段插入 YAML frontmatter、一级标题和开篇说明之后的文件前部，使入口容易被发现，同时不打乱后续原有章节。
3. 根 `CLAUDE.md`、`GEMINI.md` 或 `.github/copilot-instructions.md` 已存在时，同样只在原文件中补缺失的导入或指针，不覆盖厂商专属内容；只有对应入口不存在时才创建薄入口。
4. Cursor、Windsurf、Cline、Devin、Junie 和 Continue CLI 已可直接使用 `AGENTS.md`，默认不生成第二份完整规则。只有客户端确实不读取 `AGENTS.md` 且已有对应规则目录，才增加指向同一项目记忆入口的短规则。
5. 所有入口只负责说明智能体如何工作、何时读取和维护 Project Memory，以及不同信息应该写在哪里。项目状态、近期进展、部署步骤、环境值、测试证据和历史结论只能进入权威来源或 Project Memory。
6. 同一条完整规则只保留一份。薄入口可以导入或指向 `AGENTS.md`，不能复制整份内容；无法导入时，只重复 Project Memory 的最短触发指针。

## 保留式更新

- `AGENTS.md` 已有同名章节时，在原结构中补缺，不重复新增章节。
- `CLAUDE.md` 已包含有效的 `@AGENTS.md` 导入时不改；没有时加入一行导入，并保留其他内容。
- `GEMINI.md` 已包含有效的 `@./AGENTS.md` 或等价导入时不改；没有时加入一行导入，并保留其他内容。
- `.github/copilot-instructions.md` 已经指向 Project Memory 时不改；没有时追加短入口。
- 再次执行初始化时先识别已经注入的章节、导入和指针；已完整时保持文件不变。
- 发现相互冲突的既有规则时记录冲突并请求用户选择，不静默覆盖。
